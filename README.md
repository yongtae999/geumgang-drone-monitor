# 🛸 금강유역환경청 천내리 생태계교란식물 제거사업 3D 드론 모니터링 시스템

2026년 금강유역환경청 및 (사)야생생물관리협회의 **천내리습지 생태계교란식물(가시박 등) 제거사업** 현장 관제 및 일일작업결과 시각화 플랫폼입니다.

---

## 🌟 주요 기능

1. **3D 드론 시점 가상 비행 & 실시간 HUD**
   - 고해상도 위성 맵(Esri World Imagery) 및 3D 지형 틸트(Pitch 65°)
   - 강줄기(1구간 제원대교 → 2구간 천내리습지 → 3구간 하류)를 따라 순회하는 자율 비행 투어(Flight Tour)
   - 방위각 나침반, 고도계, 대지속도, GPS 위·경도 전술 HUD 계기판

2. **실제 현장 사진 65장 GPS 핀포인트 연동**
   - 현장 작업 사진의 EXIF GPS 좌표를 추출하여 지도 상의 정확한 위치에 펄싱 카메라 핀으로 표시
   - 핀 클릭 시 고해상도 원본 사진, 촬영 일시, 고도, 방위각 및 소속 구간 정보 표출
   - **「이 지점으로 드론 이동」** 퀵 플라이 기능

3. **1·2·3구간 식생 & 누적 제거 실적 대시보드**
   - **1구간 (A)**: 28,836 ㎡ (진척률 62.4%)
   - **2구간 (B)**: 72,803 ㎡ (진척률 65.9%, 가시박 대군락지)
   - **3구간 (C)**: 43,167 ㎡ (습지 하류부)
   - 총 목표 144,806 ㎡ 중 **누적 66,000 ㎡ (45.6%) 제거 완료**
   - 교란식물별(가시박 68%, 환삼덩굴 22%, 돼지풀 10%) 및 제거 방식별 통계 차트

4. **[별지서식 2] 생태계교란식물 제거사업 일일작업결과표 작성 & 인쇄**
   - 공공기관 표준 서식 폼 제공
   - 관공서 제출용 A4 규격 원클릭 인쇄 및 PDF 저장 지원
   - 작업 완료 항목 필터링 및 실시간 데이터 저장
